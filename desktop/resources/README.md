# Resources Directory

Place the following icon files here for the packaged desktop app:

- `icon.ico`  — Windows app icon (256×256)
- `icon.icns` — macOS app icon
- `icon.png`  — Linux app icon (512×512)
- `tray-icon.png` — System tray icon (32×32 or 64×64, ideally transparent background)

You can generate these from a single 1024×1024 PNG using:
  https://www.electronforge.io/guides/create-and-add-icons
  or
  npx png2icons icon.png resources
